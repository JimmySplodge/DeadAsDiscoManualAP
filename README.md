This is a manual randomizer for Dead As Disco! It utilizes both the Infinite Disco and the main missions.

The goal of this randomizer is to beat all 4 "Boss Levels" in Dead As Disco. Throughout the randomizer, you will unlock new Challenges and the option to unlock new skills.

**How to Play**

This randomizer needs a save file with all skills unlocked and all Challenges available. To begin, reset your entire skill tree - leaving you only with the 5 Idol Abilities unlocked throughout the game (as these cannot be disabled). The randomizer will provide you with one challenge to start with, and you will unlock more as the game goes on.

**Locations**

Each challenge and Boss Level provides three rewards upon completion. You can choose to release these based on number of completions (need to complete a level 3 times to get all 3 rewards) or on number of stars (3 Stars = 3 Rewards). The locations are split into three types - at the start, you will only get regular challenges. The Boss Challenges (Double Trouble, Arora Protocol, The Machine, Two Way Prophet, Match Made In Heaven, Four Reunion Tour) and the Boss Levels (Hemlock, Arora, Dex, and Prophet) are placed later in logic - so you will get some upgrades before having to take them on. The current version has a total of **159 Checks** to complete.

**Items**

The randomizer sends out two types of items - Level Unlocks and Upgrades. Level Unlocks should be self explanatory - they give you access to complete a new Challenge / Boss Level. The Skill Upgrades give you a "point" to spend on unlocking any skill you want from the specified tree. You are free to change around the selected skills at any time.
